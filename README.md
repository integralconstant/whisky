# WHISKY NOTE

위스키와 칵테일을 이름, 재료, 향미 태그로 탐색하는 한국어 웹페이지입니다. React, TypeScript, Vite로 구현했습니다.

## 실행

**웹페이지만 볼 때는 `index.html`을 더블클릭하면 됩니다.** 같은 폴더의 `preview.html`로 자동 연결됩니다. `preview.html`은 JavaScript, 스타일, 사진을 포함한 단일 HTML이므로 서버 없이 직접 열거나 파일 하나만 복사해서 사용할 수도 있습니다. 네트워크가 없어도 검색과 상세 보기가 작동하며, 온라인 글꼴 대신 시스템 글꼴로 표시됩니다.

소스를 수정하면서 개발할 때는 다음 방법을 사용합니다.

Node.js 22.12 이상이 필요합니다.

```sh
npm install
npm run dev
```

브라우저에서 개발 서버가 출력하는 주소(기본 `http://localhost:5173`)로 접속합니다. 소스를 수정한 뒤 직접 열기용 HTML에도 반영하려면 `npm run build`를 실행하세요.

```sh
npm run build     # 타입 검사, 배포용 dist 및 직접 열기용 preview.html 생성
npm run build:standalone # 직접 열기용 preview.html만 갱신
npm run preview   # 배포 결과 미리 보기
npm test          # 검색, 필터, 정렬, 저장 복구, 수량 계산 검증
npm run test:browser  # 실제 브라우저에서 주요 사용자 흐름 검증
npm run update:prices # 데일리샷 공개 스토어 가격 스냅샷 갱신
npm run update:images # 확인된 출처에서 누락된 위스키 사진 저장
```

브라우저 테스트는 Windows에서 설치된 Microsoft Edge를 사용합니다. 다른 운영체제에서는 먼저 `npx playwright install chromium`을 실행하세요.

## 구현한 기능

- 위스키 아카이브와 칵테일 레시피, 두 개의 주 메뉴
- 한글·영문 이름, 증류소·생산지, 태그와 칵테일 재료 검색
- 종류, 국가, 향미에 따른 복합 필터 및 개별 필터 해제
- 여러 국가 선택은 OR, 여러 향미 태그 선택은 AND 조건
- 추천순·이름순·도수순·조리 시간순 및 위스키 가격 낮은순·높은순 정렬
- 페이지당 10·25·50개 선택과 이전·다음·페이지 번호 이동
- 데일리샷 스토어 평균가, 동일 용량의 판매가 수, 기준일, 최저·최고가와 개별 출처
- 6개 향미 그룹의 42개 태그와 제품별 향·맛·여운에 근거한 세부 태그 검색
- 캐스크 스트렝스(CS) 태그 필터와 `CS`, `Cask Strength`, `Barrel Proof` 검색
- 스카치 배치를 대표 카드 하나로 묶고 상세 화면에서 배치별 정보·사진·판매가 선택
- 위스키의 도수, 숙성 연수, 향·맛·여운, 공식 브랜드 출처
- 칵테일의 재료, 만드는 순서, 잔, 소요 시간, 공식 레시피 출처
- 1–6잔 재료량 계산과 레시피 복사
- 브라우저에 유지되는 북마크 컬렉션
- 모바일 필터, 반응형 화면, 키보드 검색(`/` 또는 Ctrl/Cmd+K)
- 상세 창의 Escape 닫기, 키보드 포커스 관리, 검색 결과 안내

## 데이터 범위와 확장

현재 카탈로그는 **10개 국가·지역의 위스키 434종(개별 배치 포함 480개 항목)과 칵테일 18종**입니다. 캐나다 25종과 대만 15종을 포함하며, 전 세계 모든 위스키를 망라한 데이터베이스는 아닙니다. 각 항목에 브랜드·IBA·공개 제품 페이지의 출처 URL을 기록했습니다. 향미 태그·한국어 요약·칵테일 난이도·소요 시간은 탐색을 돕기 위해 편집한 정보입니다. 위스키 도수는 확인한 병입 기준으로, 출시 국가에 따라 다를 수 있습니다.

CS 제품은 **36종(개별 배치 포함 79개 항목)을 캐스크 스트렝스 태그로 검색**할 수 있습니다. `라프로익 CS`처럼 제품명과 조합하거나 국가·향미 태그와 함께 필터링할 수 있습니다. 높은 도수만으로 CS로 분류하지 않습니다.

배치가 지정된 제품은 해당 배치의 도수와 숙성 정보를, 배치에 따라 달라지는 제품은 공식 범위 또는 안내된 병입의 기준 도수를 표시합니다. 상세 화면의 도수 안내에서 기준을 확인할 수 있습니다. 도수가 범위로 표시되는 제품은 **범위의 하한으로 도수 정렬**합니다.

글렌알라키 10년 CS(배치 1–13), 글렌알라키 21년 CS(배치 1–7), 라프로익 10년 CS(배치 1–17), 부나하벤 12년 CS(2025·2023), 옥토모어 아일라 보리 .3(17.3·16.3), 탐두 배치 스트렝스(006·007·008), 글렌드로낙 CS(배치 10–12), 하이랜드 파크 CS(릴리즈 1–5), 맥네어스 럼 릭 10년 CS(배치 1–3)는 목록에 각각 하나의 대표 카드로 표시합니다. 카드에는 도수와 가격의 기준 배치를 표시하고, 상세 화면의 **배치 선택**을 바꾸면 제품명·도수·향미·사진·제품 출처·데일리샷 판매가가 함께 변경됩니다. 연산이나 캐스크 표현이 다른 제품은 별도로 유지합니다.

검색과 향미 필터는 모든 배치에 적용한 뒤 대표 카드로 묶습니다. 특정 배치명으로 검색하거나 이전 배치를 북마크한 경우에는 해당 배치로 상세 화면이 열립니다. 북마크는 배치별로 유지하며, 컬렉션 개수와 목록은 제품군마다 한 번씩 계산합니다. 가격·도수 정렬은 카드에 실제 표시하는 배치 기준입니다.

- `src/data/types.ts`: 데이터 형식
- `src/data/whiskies.ts`: 초기 위스키 항목과 전체 카탈로그 통합
- `src/data/whiskies-*.ts`: 스페이사이드·스코틀랜드·미주·세계·캐나다·대만별 추가 위스키
- `src/data/whiskies-cs-*.ts`: 스코틀랜드·미국·기타 국가의 CS 제품과 배치별 도수 안내
- `src/data/whiskies-scotch-batches.ts`: 선택 가능한 스카치의 다른 배치 정보
- `src/data/whiskies-glenallachie-21-batches.ts`: 글렌알라키 21년 CS 배치 1–7
- `src/data/whiskies-more-scotch-batches.ts`: 글렌알라키 7–11, 탐두 007·008의 배치별 정보
- `src/data/whiskies-glenallachie-early-batches.ts`: 글렌알라키 10년 CS 배치 1–6
- `src/data/whiskies-macnairs.ts`: 맥네어스 럼 릭 12년·21년, 10년 CS 배치 1–3
- `src/data/whiskies-more-cs-america.ts`: 러셀 13년 2025, 올드 포레스터 배럴 스트렝스, 스텔럼 버번
- `src/data/whiskies-glendronach-cs.ts`: 글렌드로낙 CS 배치 10–12
- `src/data/whiskies-highland-park-cs.ts`: 하이랜드 파크 CS 릴리즈 1–5
- `src/data/whiskies-laphroaig-cs-batches.ts`: 라프로익 10년 CS 배치 1–15
- `src/data/whiskies-laphroaig-travel.ts`: 라프로익 PX 캐스크·면세 전용 12년 등 여행 소매 제품
- `src/data/scotch-batch-groups.ts`: 같은 표현의 배치 목록, 대표 배치와 공통 제품명
- `src/data/bottlings.ts`: 기존 제품의 CS 여부를 확인한 생산자 출처
- `src/data/whisky-catalog-helpers.ts`: 생산자 공통 정보와 제품별 정보를 결합하는 도우미
- `src/data/flavors.ts`: 기존 테이스팅 노트에서 세부 향미를 추출하는 편집 규칙과 필터 그룹
- `src/data/dailyshot-prices.json`: 확인한 판매가와 평균을 담은 가격 스냅샷
- `src/data/dailyshot-products.json`: CS 상품 링크와 배치별 가격 연결 기준
- `src/data/whisky-images.json`: 추가 사진의 로컬 경로, 원본 URL, 제품명과 확인일
- `src/data/cocktails.ts`: 칵테일과 레시피
- `src/lib/catalog.ts`: 검색·필터·가격 정렬·페이지 계산·저장 복구·재료량 계산
- `src/lib/batches.ts`: 스카치 배치 묶음과 상세 선택 목록
- `src/App.tsx`: 화면과 사용자 상호작용
- `src/styles.css`: 데스크톱·태블릿·모바일 스타일

기존 데이터 그룹에 고유 `id`를 가진 항목을 추가하면 검색 결과, 종류별 개수, 국가 필터와 전체 개수가 자동으로 갱신됩니다. 새 `whiskies-*.ts` 파일을 만들 때는 내보낸 배열을 `whiskies.ts`에서 가져와 전체 배열에 포함하세요. `npm test`는 모든 지역별 파일의 항목이 실제 카탈로그에 연결되었는지도 확인합니다. 위스키 종류는 `types.ts`의 형식과 일치시켜야 하며, 향미 태그는 화면의 선택지와 동일한 어휘를 사용하세요. 사진이 없는 항목은 앱에 포함된 병 또는 잔 일러스트로 표시합니다.

전체 시장을 포괄하는 서비스로 확장하려면 제품 데이터 제공처와 연결하고, 서버 데이터베이스·관리 화면·정기 업데이트를 추가해야 합니다. 현재는 별도 서버나 API 키가 필요 없는 정적 웹앱입니다. 컬렉션은 해당 브라우저의 `localStorage`에 보관되며 기기 간 동기화는 하지 않습니다.

확장은 증류소 단위로 진행합니다. 현재 라프로익의 누락 제품·배치·한정판을 확인 중이며, 전체 제품 확인과 등록을 마친 뒤 다음 증류소로 넘어갑니다. 진행 목록은 `scripts/catalog-candidates/laphroaig-inventory.json`에 보관합니다.

## 가격과 페이지 표시

평균가는 데일리샷의 **판매 중인 스토어 등록가**를 같은 제품·도수·용량끼리 모아 계산한 스냅샷입니다. 공개 판매처 목록의 전체 페이지를 확인하며, 세트 상품·품절 항목·중복 등록은 집계에서 제외합니다. 파트너와 편의점 채널, 쿠폰·적립 혜택·배송비를 포함한 결제 금액의 평균은 아닙니다. 상세 화면에서 용량, 기준일, 집계 건수와 개별 판매가 링크를 확인할 수 있습니다.

동일 제품으로 확인할 수 없거나 판매가를 가져오지 못한 바틀은 `가격 정보 없음`으로 표시하며, 가격 정렬에서는 마지막에 배치합니다. 각 바틀에 표시되는 용량을 함께 비교하세요. 자동 실시간 갱신은 제공하지 않으며 `npm run update:prices` 이후 `npm run build`를 실행하면 새 스냅샷이 웹페이지와 오프라인 미리보기에 반영됩니다. 자세한 [가격 산정 기준과 갱신 방법](DAILYSHOT-PRICES.md)을 참고하세요. 수집 범위와 제외 내역은 `scripts/dailyshot-coverage.json`에 기록합니다.

전체 480개 항목 중 308개에 스토어 평균 판매가를 제공합니다. CS는 배치 포함 79개 항목 모두 데일리샷 링크를 연결했고, 2026년 10월 1–17일 확인본 기준 57개에 스토어 판매가를 제공합니다. 다른 배치만 확인된 4개와 동일 상품을 확인하지 못한 15개에는 참고/검색 링크를 표시합니다. 라프로익 10년 배치 12, 탐두 006과 글렌알라키 21년 배치 7은 정확한 상품을 연결했지만 구매 가능한 국내 스토어 판매가가 없어 금액을 표시하지 않습니다. 공용 CS 상품의 가격은 상세 화면에 판매 배치·도수 조건을 안내합니다. `npm run update:prices -- --cs`로 CS만 갱신할 수 있습니다.

10월 7일 추가한 글렌알라키 10년 CS 배치 1–6과 맥네어스 럼 릭 5개 항목은 모두 배치·표현별 사진과 판매가를 연결했습니다. 글렌알라키 배치 1·2의 가격 비교 용량은 750ml이며, 배치 2에 섞인 700ml 판매분은 평균에서 제외했습니다.

페이지당 개수와 검색·필터·정렬을 변경하면 첫 페이지로 돌아갑니다. 북마크 변경으로 마지막 페이지가 사라지면 남아 있는 마지막 페이지를 표시합니다. 칵테일 목록에도 같은 페이지당 개수 설정을 적용하며, 가격 정렬은 위스키에서만 제공합니다.

## 이미지

위스키는 **개별 배치를 포함한 480개 항목 모두 실물 제품 사진**을 표시합니다. 기존 6종에 474개 사진을 추가했으며, 브랜드 공식 페이지·데일리샷·공개 상품 페이지에서 제품명, 연산과 에디션을 대조했습니다. 출시 시장·시기에 따라 병과 상자 디자인은 달라질 수 있습니다. 기존 대표 사진은 The Whisky Exchange, 라이프스타일 사진은 Unsplash에서 가져왔습니다.

사진은 `public/images/`에 저장되어 카드와 상세 화면에서 같은 파일을 사용합니다. 추가 사진의 출처는 `src/data/whisky-images.json`, 수집 대상으로 확인한 URL은 `scripts/whisky-photo-sources-*.json`, 누락·실패 목록은 `scripts/whisky-image-coverage.json`에 기록합니다. 사진을 읽지 못하면 병 일러스트로 대체합니다.

`npm run update:images`는 이미 저장된 파일을 유지하고 누락된 사진만 가져옵니다. 특정 사진을 교체하려면 출처 JSON을 수정하고 `npm run update:images -- extra --ids=제품ID --refresh`를 실행하세요. 이후 `npm run build`로 배포 파일과 `preview.html`을 갱신합니다. `preview.html`은 모든 사진을 포함하므로 용량이 수십 MB이며, 파일 하나만 복사해도 오프라인에서 사진·검색·상세 보기가 작동합니다. 글꼴은 Google Fonts를 사용하며 연결되지 않으면 시스템 글꼴로 표시됩니다.

## 배포

`npm run build`로 생성되는 `dist/`를 정적 호스팅에 올리면 됩니다. GitHub Pages는 `main` 브랜치에 푸시할 때 GitHub Actions가 자동으로 빌드·배포합니다. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하세요.

배포 주소: https://integralconstant.github.io/whisky/ . GitHub Actions에서는 `/whisky/` 하위 경로에 맞게 Vite와 이미지 경로를 설정하며, 로컬 개발과 루트 경로 배포는 기존 기본 설정을 사용합니다.
